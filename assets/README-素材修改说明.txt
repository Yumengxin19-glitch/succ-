# GitHub Pages 课程素材

本压缩包由法语跟读程序自动生成。

## 文件结构

- assets/subtitles.json：字幕、时间节点、中文、音标
- assets/video.mp4：视频
- assets/audio/sentences/<字幕ID>.mp3：对应字幕句子的自定义音频
- assets/audio/words/<单词名>.mp3：对应单词的自定义发音

无需 audio-manifest.json。

## 上传方式

解压后，把 assets 文件夹上传/覆盖到 GitHub 仓库根目录；index.html 使用零维护文件名自动读取这些资源。

本次导出：22 句字幕，12 个句子自定义音频，3 个单词自定义音频。
